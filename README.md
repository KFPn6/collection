# collection

いうたさんが所有しているコレクション（ポケモンカードなど）の台帳です。
チャットで「○○を登録して」と頼まれたら、この台帳にアイテムを追加・更新します。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `data/collection.yaml` | 正本。追加・更新はここを編集する |
| `README.md` | 項目の説明と、人が見る一覧表 |

仕組みはこれだけです。データベースやアプリはありません。

## 項目

| キー | 項目 | 説明 |
| --- | --- | --- |
| `id` | ID | 通し番号。既存の最大値に 1 を足す。あとから変えない |
| `category` | カテゴリ | 例: ポケモンカードゲーム |
| `name` | 商品名 | 公式表記が分かるときは公式の商品名を使う |
| `kind` | 種類 | 例: 構築済みデッキ、拡張パック、デッキセット |
| `quantity` | 数量 | 持っている個数（整数） |
| `condition` | 状態 | `未開封` または `開封済み`。不明なら `null` |
| `release_date` | 発売日 | `YYYY-MM-DD`。不明なら `null` |
| `list_price` | 定価（税込） | 希望小売価格。円の整数。不明なら `null` |
| `purchase_date` | 購入日 | `YYYY-MM-DD`。不明なら `null` |
| `purchase_price` | 購入価格 | 実際に支払った金額。円の整数、税込。不明なら `null` |
| `store` | 購入店 | 店名。不明なら `null` |
| `memo` | メモ | 自由記述。なければ `null` |
| `official_url` | 公式URL | 公式商品ページ。なければ `null` |
| `registered_on` | 登録日 | この台帳に登録した日。`YYYY-MM-DD` |

不明な項目は空欄（`null`）にします。「未確認」という文字は入れません。

## 登録のしかた

1. `data/collection.yaml` の `items` の末尾に、上の項目をそろえた1件を足す。
2. 発売日と定価は、分かる範囲で公式ページ（ポケモンカードなら [pokemon-card.com](https://www.pokemon-card.com/)）を見て、違えば公式の値を使う。商品ページの URL を `official_url` に残す。
3. 下の一覧表に同じ内容の行を足す。YAML が正本で、表は見やすさのためです。

更新するときは、同じ `id` の項目と表の行を直します。
